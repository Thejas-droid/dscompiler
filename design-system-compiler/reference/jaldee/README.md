# Jaldee Figma reference

This folder records the supplied Figma export metadata and thumbnail used while implementing the demo theme. The source `.fig` archive remains external to the repository.

The demo uses a purple brand accent sampled from the supplied thumbnail and a cool blue secondary accent sampled from embedded progress-component reference imagery. Exact Figma variable parity is handled by the included Figma plugin's drift comparison flow rather than by guessing variable definitions from raster previews.
